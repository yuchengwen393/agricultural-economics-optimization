# 实地补采与模型接入

用途：将半实证研究设计升级为真实经营实例。生成逻辑：由缺口与资源模拟变量反推。

空模板仅字段清单，没有虚构样本，不可作为求解数据。订单面积、时间与诊断须由用户/服务方确认；入口与补水点需要机手现场核实；关键转场优先GPS测量。班组状态需记录电池剩余电量、就绪时间、充电器及药液，不应每次重规划重置满库存。外援只使用已接受报价包，保留退出/替代订单约束。药剂适用、障碍、禁飞和天气需按任务要求独立核验。跨户数据需匿名化。

真实入口不应仅覆盖格网中心；真实订单数量与空间范围变化后须重建网格支持/矩阵/路线池，并重跑全部验证。ground_compatible只能在设备及入口核验后开放。
