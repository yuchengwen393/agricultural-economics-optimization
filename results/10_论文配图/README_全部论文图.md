# 全部15幅论文图

用途：论文配图、后续修改与数据追溯。生成逻辑：assemble_visual_package.py按最终Word图号汇总。

PNG_600dpi用于Word插图；SVG_矢量用于无损缩放，文字已路径化以避免字体替换；PDF图集保留矢量与嵌入字体。中英文分别采用微软雅黑加粗与Arial Bold，图例、坐标、数据标签统一加粗，主轴线与辅助线区分粗细。

绘图数据共35份，数值原样保留未舍入精度；每表含purpose与generation_logic。论文图号不同于历史原图号，使用本目录图号，不要再把08目录原图号直接当作论文编号。图表目录与数据映射.csv列出对应关系。

PNG/SVG二进制用途与生成逻辑详见交付文件清单.csv和图表映射表。图集不是论文分页检查PDF。
